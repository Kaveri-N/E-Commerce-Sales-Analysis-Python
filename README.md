# E-Commerce Sales Analysis using Python

## 📌 Project Overview

This project analyzes e-commerce sales data using Python to identify important business trends, customer patterns, product performance, and revenue drivers.

The analysis focuses on sales performance, product categories, sales channels, customer segments, return rates, discounts, and monthly revenue trends.

The goal is to generate meaningful business insights that can support data-driven decision-making.

---

## 🎯 Project Objectives

* Analyze overall sales and revenue performance
* Identify monthly revenue trends
* Find the highest-performing product categories
* Analyze revenue generated by sales channels
* Compare customer segments
* Identify top-performing products
* Analyze product return rates
* Understand the impact of discounts on revenue
* Generate actionable business recommendations

---

## 📊 Dataset

The dataset contains **8,000 e-commerce order records**.

### Key Columns

| Column       | Description                   |
| ------------ | ----------------------------- |
| order_date   | Date of the order             |
| order_id     | Order identifier              |
| customer_id  | Customer identifier           |
| customer     | Customer name                 |
| segment      | Customer segment              |
| channel      | Sales/marketing channel       |
| product_id   | Product identifier            |
| product      | Product name                  |
| category     | Product category              |
| quantity     | Quantity purchased            |
| unit_price   | Price per unit                |
| discount_pct | Discount percentage           |
| line_total   | Total value of the order line |
| returned     | Return indicator              |

---

## 🧹 Data Cleaning

The following data quality checks were performed:

* Converted `order_date` into datetime format
* Checked for missing values
* Checked for duplicate records
* Verified positive quantity values
* Verified positive unit prices
* Validated discount percentages
* Validated `line_total` using quantity, unit price, and discount
* Checked returned orders

The dataset was found to be clean and suitable for analysis.

## 📈 Key Results

* **Total Revenue:** ₹4,87,706.66
* **Total Orders:** 4,400
* **Average Order Value:** ₹110.84
* **Overall Return Rate:** 5.48%
* **Top Category:** Electronics
* **Top Sales Channel:** Email
* **Top Customer Segment:** Loyal
* **Top Product:** USB-C Cable
* **Highest Return Rate Category:** Electronics (5.83%)

---

## 💡 Key Business Insights

### 1. Electronics Performance

Electronics was the highest revenue-generating product category, making it an important business segment.

### 2. Email Marketing

Email generated the highest revenue among all sales channels, indicating strong potential for email marketing campaigns.

### 3. Loyal Customers

The Loyal customer segment contributed the highest revenue, highlighting the importance of customer retention strategies.

### 4. Top Product

USB-C Cable was the highest-performing product by revenue.

### 5. Product Returns

The overall return rate was 5.48%, while Electronics had the highest category-level return rate at 5.83%.

### 6. Monthly Sales Trend

Revenue increased from September 2025 and reached its highest level in December 2025.

## 🚀 Business Recommendations

* Focus marketing and inventory planning on the Electronics category.
* Strengthen email marketing campaigns to improve sales.
* Introduce loyalty programs and personalized offers for high-value customers.
* Promote high-performing products such as USB-C Cable.
* Investigate the reasons behind higher returns in Electronics.
* Improve product descriptions, packaging, and quality checks.
* Optimize discount strategies to increase revenue while protecting profitability.
